# AI Vision Studio Website

A responsive, single-page creative studio website built with plain HTML, CSS and JavaScript.

## Preview
Open `index.html` in a browser. Internet access is used only for the Google Fonts import; the layout and graphics are created in CSS.

## Before publishing
1. Open `contact-config.js` (or edit the contact link in `index.html`) and replace the demo email `hello@aivisionstudio.in` with your real email.
2. Add your real WhatsApp number if you want a WhatsApp CTA. No number has been invented or hard-coded.
3. Replace project descriptions/screens with final client-approved work where needed.
4. Upload the folder contents to GitHub and connect the repository to Vercel. No build command is required; this is a static site.

## Files
- `index.html` — page content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and footer year
